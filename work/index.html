What I've built, and what changed because of it.

Each project below says who it was for, what was hard, what I built and what changed. Client names are left out on purpose. Every project is marked as a delivered system, a working demonstration or a private beta, so you can see which is which.

Working demonstration

For a self-catering bush lodge

A guest companion that looks after the guest before, during and after the stay.

What was hard
The owner thought an app might help but didn't know what it would be. There was a website and an open conversation, not a brief.
What I built
A personal guest app for each booking, opened from a link on the guest's phone: countdown and checklist, arrival directions, weather, nearby food and care, a wildlife passport and a trip memories card.
Where it stands
It works today as a demonstration. It isn't a deployed commercial product, it isn't connected to a booking system, and I haven't measured time savings.

One shared app with one content file per lodge, so setting up a new lodge changes content rather than code. It works offline once opened, in English and German.

Delivered system

For a Cape Town manufacturer of premium wellness equipment

Customers follow their order online. The phone stopped ringing.

What was hard
Each custom order takes six to fourteen weeks to build and can be worth R50,000 to R250,000 or more. Customers want to know how it's going.
What I built
A private page for each customer with a nine-step progress timeline, photos the business approves before the customer sees them, and the quote, deposit and balance kept up to date. Workshop staff add photos by scanning a QR code, with no login.
What changed
Support calls during the build phase dropped to zero.

The screen is an illustrative preview with sample information, not a screenshot of the client's system. The ready-made version of this is BuildTrack.

6 hoursof write-up saved for the observer after every swim
Delivered system

For an open-water swimming ratification body

The paperwork is done by the time the swim ends.

What was hard
An observer on the boat watches a swim for hours, then has to write it all up before it can be assessed.
What I built
An app that works offline on the boat. The observer records check-ins, feeds, attire and incidents with a time and location as they happen. The moment the swim ends, the evidence is assembled and sealed. The ratifying body reviews it, asks questions, decides and issues certificates in the same place, on a record that can't be quietly changed.
What changed
It saves the observer six hours of write-up after every swim. I built it in eight days.
Technical detail, if you want it

Offline capture, timestamped and location-tagged. Evidence is sealed with a SHA-256 fingerprint when capture ends, and the review record is append-only. 26 database tables.

Delivered system

For a large enterprise moving to a new SAP system

Problems found in the old data before they became problems in the new system.

What was hard
A company moving to a new system has to be sure its existing data is clean first, and nobody can check that by hand.
What I built
Fifty-five automatic checks that run every day against the live data, with reports that explain in plain English where each kind of problem comes from.
What changed
171,000 issues were found before go-live.
Technical detail, if you want it

Rules run daily against live SAP S/4HANA master data. GPT-powered root-cause reporting turns each failed check into an explanation.

Delivered system

For an open-water swimming community

One app, three clubs, 780 swimmers in 16 countries.

What was hard
A swimming community spread across several clubs and countries needed one shared place to log swims, plan group events and pass on safety information.
What I built
A phone app where swimmers log swims with location, conditions and hazards, clubs run events with safety checks, and members take part in challenges. Adult open-water clubs and junior squads with coaches, attendance and parent links all run on the same shared platform.
What changed
780 swimmers across 16 countries and three clubs now use one app. The ready-made version is LoadKit.
Technical detail, if you want it

One codebase serves all three clubs. Includes location-based logging, push notifications and sponsor placements.
